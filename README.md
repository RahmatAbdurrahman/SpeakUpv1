# SpeakUp

**Public Speaking Training Mobile Web App** — IndonesiaNext Project

SpeakUp adalah aplikasi web interaktif yang dirancang untuk melatih dan meningkatkan kepercayaan diri serta keterampilan public speaking melalui modul pelatihan terstruktur, evaluasi AI real-time, dan latihan interaktif.

## 🚀 Tech Stack
- **Framework**: React 18 + Vite
- **Styling**: Vanilla CSS Design System with CSS Variables (`design.md`)
- **Typography**: Space Grotesk
- **Audio & Media**: Interactive video & audio recorder

## 🛠️ Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```

Spesifikasi lengkap token desain, palet warna, tipografi, dan aturan komponen dapat dilihat pada [design.md](./design.md).
